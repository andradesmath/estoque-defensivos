# Dependências do robô local scripts/sync_compras_sgi.py (roda no Windows do SGI, NAO no
# GitHub Actions nem no Streamlit Cloud). Precisa do Python de 32 bits, mesma arquitetura
# do SGI.exe, senao pywinauto nao enxerga os controles da janela corretamente:
#   py -3.11-32 -m pip install -r requirements-local-robo-compras.txt
#
# Sem pandas de propósito: não existe build pronta de pandas para Windows 32 bits em
# nenhuma versão compatível com Python 3.11 (só compila do zero, exige toolchain que
# essa máquina não tem). O parser usa xlrd (puro Python) em vez de pandas.
#
# pg8000 (e não psycopg2-binary) pelo mesmo motivo: psycopg2-binary também não tem build
# pronta para Windows 32 bits, e compilar exige o pg_config/toolchain do Postgres. pg8000
# é driver Postgres em puro Python. O .env desta máquina aponta para ele no esquema da
# URL: DATABASE_URL=postgresql+pg8000://...  (o painel e o GitHub Actions seguem com
# psycopg2 normalmente - ver estoque/db.py).
